# The Beautiful Game · 2026 World Cup Pool (prep site)

A standalone prep and briefing site for our 2026 World Cup draft pool. It explains
the game, the draft, and the payouts; lets everyone scout the field (countries,
attackers, keepers) with live odds and photos; and lays out the full tournament
schedule with kickoff times. There are no live standings and no live draft. This
is the homework, not the scoreboard.

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy

It is static, so drop the folder on Vercel, Netlify, or GitHub Pages as is.

## Structure

| File | What is in it |
|------|---------------|
| `index.html` | Entry point that loads data plus app |
| `styles.css` | Design system (warm newsprint, electric-blue plus magenta accents) and all components |
| `data.js` | All content: pool config, prizes, rules, the 48 countries / 24 attackers / 14 keepers (with copy, odds, and photos), and the full schedule |
| `app.js` | Vanilla-JS app with five screens (Overview, How to Play, Payouts, Scouting, Schedule) |

`data.js` is generated by `/tmp/wc_build/build-data.js`, which merges the base
scouting data with the copy, odds, photo, and schedule research. To hand-edit,
just edit `data.js` directly.

## Edit the pool numbers

The buy-in, pot, team count, and six prize amounts are placeholders. Set your real
numbers in `data.js`:

- `POOL` for buy-in, pot, team count, dates
- `PRIZES` for the six cash prizes (they should sum to `POOL.pot`)
- `DRAFT` and `RULES` for draft format and rules copy

## Data sources

- Country and player scouting copy comes from the `2026 World Cup Pool Draft Guide.xlsx`, rewritten for the site.
- Odds reflect early-June 2026 books: country title and reach-final odds, attacker Golden Boot and Goals+Assists lines, and keeper Golden Glove odds. Refresh before the draft.
- The schedule (group draw, all 72 group-stage fixtures with Eastern kickoff times and venues, and the knockout calendar) reflects the finalized 2026 tournament draw.
- Player photos are pulled from Wikipedia and fall back to a monogram if an image fails to load.

## Design

Built on the Claude Design handoff (538 and WSJ editorial data-desk look),
re-skinned with a warm newsprint background, electric blue as the primary accent,
hot magenta for flourishes, and real flag images via flagcdn.com.
